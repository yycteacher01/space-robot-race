第一屆太空機械人競速賽｜Google Sheet 即時分數及時間排名設定

一、排名方式
每場獨立排名，可切換項目一、項目二及兩項總成績。
項目一上限420秒；項目二360秒，依據最新記分表。
每項兩次機會先按分數高低、同分按比較時間短取較佳一次，保留該次完整分數及時間，不可拼合。分數須填0至100的單次得分（已扣除救援分）。
兩項總成績：兩項均有有效成績（可為未完成），各取選定機會分數及比較時間相加，先比總分、同分再比時間總和。
相同分數及時間並列（1、1、3）；隊號排序只用作並列隊伍展示，不破同分。
頁面標明：排名按分數高低，同分再比較時間速度。最終賽果以裁判為準。

二、已建立的Google試算表
https://docs.google.com/spreadsheets/d/1CsbL8KaRxxKcpNYNvPu61NqI5TOOxrXyl9O6uSXLTLI/edit
計分表位於Google Drive的ChatGPT資料夾。三場各30隊，四個狀態欄均有選單。
1. 開啟上方已建立的試算表。
2. 擴充功能 → Apps Script；將網站的已填妥Code.gs全部貼上並儲存。
3. 不須執行setupCompetition，來源試算表ID已填好。
4. 直接按下節部署。狀態只有完成並具有有效時間才上榜。

三、部署與連接
1. Apps Script：部署 → 新增部署作業 → 網頁應用程式。
2. 執行身分選「我」；存取權選「所有人」。學校帳戶若無此選項，需管理員允許或大會批准帳戶。
3. 複製以/exec結尾的部署網址，不使用/dev。
4. 排名網站 → 連接與設定 → 貼上網址 → 連接並讀取資料。
5. 預設每5秒讀取，可改10、15、30秒。資料端點唯讀，不會更改成績。
6. 用「複製帶資料來源的看板連結」在另一電腦開啟。網站瀏覽權限依 GitHub Pages 設定；試算表的編輯權限仍由 Google 獨立管理。
7. Apps Script端點可由知道網址的人讀取，只輸出隊號、隊名及成績。Google Sheet不必開放匿名編輯。
8. 更新Apps Script後，須在「管理部署作業」更新部署至新版本。

四、輸入方式
15欄依序為：隊號、隊伍名稱、學校、項目一第1次分數、項目一第1次時間、項目一第1次狀態、項目一第2次分數、項目一第2次時間、項目一第2次狀態、項目二第1次分數、項目二第1次時間、項目二第1次狀態、項目二第2次分數、項目二第2次時間、項目二第2次狀態。
請勿改欄位名稱、次序或工作表名稱。
隊號必填且同場唯一。最多90隊總規劃，每場預設30個隊位。
時間為純文字：1:23.45、83.45或1:23:45，均指83.45秒；最後一欄為百分秒。
狀態：未出賽／完成／未完成／無效。完成須分數有效、時間>0且不超限時；未完成可保留所得分，比較時間統一取該項限時；未出賽、無效不排名。
分數必填，空白不等於0分；0分是有效分數。學校欄不在網頁或匯出中展示，現有試算表欄位次序保留以相容既有連接。
請先輸入分數及時間，最後把狀態改為「完成」或「未完成」，避免半輸入資料短暫上榜。
修正已完成資料前，先將狀態設為「未出賽」或「無效」，修改後再設回「完成」。

五、使用與故障
初始頁顯示等待連接，不假裝已同步。可自行切換示範模式；真實成績只在成功連接後顯示。
可搜尋隊號、隊名，切換場次／項目、全螢幕、暫停同步及匯出分數及時間排名CSV。
斷線時保留最後成功資料，並顯示同步失敗及最後成功時間；不把讀取失敗當作全隊0分。
Google資料採定時輪詢，實際延遲受Google執行、網路及配額影響；不是無延遲推送。
多個看板同時開啟會增加Apps Script讀取次數，建議只開必要展示裝置，必要時調至10至30秒。
正式開賽前：新增測試隊伍 → 填有效時間 → 確認排名；再測同時間並列、未完成及修改時間。
完成測試後清除測試隊伍名稱。切換不同場次確認三場資料各自獨立。
